# Webhook Events - Teamwork Desk

**Event : Options**

`AGENT` : `CREATED, DELETED, UPDATED`

`CUSTOMER` : `CREATED, DELETED, UPDATED`

`HAPPINESS RATING` : `ADDED`

`INBOX` : `CREATED, DELETED, UPDATED`

`TAG` : `CREATED, DELETED, UPDATED`

`THREAD` : `DELETED, EDITED`

`AGENT` : `REPLY`

`TICKET` : `ASSIGNED, CREATED`

`CUSTOMER` : `REPLY`

`TICKET` : `DELETED`

`HAPPINESS RATING` : `ADDED`

`TICKET` : `MERGED MOVED`

`CUSTOMER` : `REPLY`

`TICKET` : `DELETED`

`HAPPINESS RATING` : `ADDED`
